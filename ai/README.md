# SelfFit AI

모델 학습·검증과, 서비스에 바로 붙는 형태로 **가중치·전처리 규약을 납품**하는 파트입니다.
추론 서버·판정·통합은 백엔드가 맡습니다. **AI 팀은 서버 코드를 짜지 않습니다.**

- 인터페이스 계약(권위 문서): [`../backend/guideline/03-for-ai.md`](../backend/guideline/03-for-ai.md)
- 이 폴더 문서: [docs/PRD.md](docs/PRD.md) · [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) · [docs/ADR.md](docs/ADR.md)

## 모델 3개

| 역할 | 모델 | 상태 |
|---|---|---|
| 시선 | L2CS-Net (ResNet50) | AI-Hub 가중치 그대로 사용 |
| 감정 | EmotionNet (경량 CNN) | **AI 팀 파인튜닝 중** |
| 집중 | Former-DFER (트랜스포머) | AI-Hub 가중치 그대로 사용 |

시선·집중은 재학습하지 않습니다. **AI 팀의 실제 학습 작업은 감정 모델 파인튜닝 하나**입니다.

## 지금 할 일

### 1. 백엔드 확인 질문 답하기 (Phase 2 전)
없으면 백엔드가 가정값으로 진행하고 샘플로 실측하므로 블로킹은 아니지만, 답하면 실측을 건너뜁니다.

| # | 질문 | 백엔드 가정값 | 백엔드 회신 |
|---|---|---|---|
| 1 | Former-DFER 5클래스 인덱스 순서 | 0 집중 · 1 졸림 · 2 집중결핍 · 3 집중하락 · 4 태만 | 가정대로 코딩됨. 판정은 **집중=인덱스0**만 중요(나머지 4개는 모두 `attention_low`로 묶음), 세부 순서는 리포트 표기용. class_idx(최소 F 위치)만 주면 실측 스킵 |
| 2 | 파인튜닝 감정 모델 구조가 EmotionNet 그대로인지 | 유지, 48×48 흑백 | 앱은 전처리 안 함(추론 서버 담당). 구조 바뀌면 규약 5절대로 network `.py` + 전처리 명세만 첨부 |
| 2-1 | 출력이 4클래스인지 7클래스 유지인지 + 인덱스 순서 (7클래스 유지도 문제없음) | 7클래스 유지, 원본 순서 | **7클래스 유지 권장**(4클래스 전환 불필요). 백엔드는 라벨 문자열로 처리 → 인덱스→라벨 매핑만 확정해 `중립/불안/당황/기쁨` 표기 일치시키면 됨 |
| 3 | 안구 학습 데이터의 얼굴 검출기·크롭 여백 | MediaPipe + 20% | 서빙 크롭은 확정(MediaPipe, 시선 20%·감정/집중 0%). NIA 원본 여백은 알면 실측 스킵, 모르면 Phase 2 실측으로 확정(블로킹 아님) |
| — | 1차 모델 납품 예상 시점 | — | (AI 팀 회신 필요) |

### 2. 감정 모델 파인튜닝
서비스 실전 조건에 맞춰 데이터를 선별합니다. 상세는 [docs/PRD.md](docs/PRD.md).
핵심: **얼굴을 MediaPipe로 100px 안팎으로 잘라 흑백 학습**, 성공 지표는 **불안 재현율 · 중립/기쁨 정밀도**.
급하지 않습니다 — Phase 2는 원본 7클래스로 먼저 통합하고, 파인튜닝 결과는 이후 언제든 교체합니다.

`inference/weights/`에 버전 파일명, git 커밋 금지(Release/Drive), 전처리·출력 명세·성능표 첨부.

## 실행

```bash
uv sync
```
