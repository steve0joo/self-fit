## 4. 이 트레이드오프를 어떻게 읽을 것인가

§6의 우선순위는 전부 통과했지만, 서비스 관점에서 두 가지를 같이 봐야 한다.

**긴장 알림(anxious ≥ 0.5가 5초 지속)은 더 잘 뜨고, 더 자주 헛뜬다.** recall +0.205는 "놓치는 긴장"이 줄었다는 뜻이고, precision −0.102는 "가짜 긴장 알림"이 늘었다는 뜻이다. 어느 쪽 오류가 더 싼지는 제품 판단이다. 3fps에서 5초 연속(15프레임)을 요구하는 규칙 자체가 산발적 오탐을 상당 부분 걸러 주므로, 프레임 단위 precision 하락이 그대로 알림 오탐률이 되지는 않는다.

**리포트의 "안정 표정 비율"은 §6이 요구한 방향으로 개선됐지만 총량은 줄어든다.** §6이 2순위로 둔 neutral **precision**은 +0.179로 크게 올랐다 — 즉 "중립이라고 부른 것"의 신뢰도는 높아졌다. 다만 neutral **recall**이 −0.197이라 실제 중립 프레임의 31%를 놓치고, 리포트의 안정 표정 비율은 **과대가 아니라 과소** 집계된다. §6은 "부풀려지는 것"을 막으려 precision을 지표로 골랐으므로 방향은 맞지만, 이 부작용은 리포트 문구를 정할 때 알고 있어야 한다.

**모델 선택 지표가 노이즈에 취약하다.** val anxious recall은 에폭마다 0.40~0.78로 크게 출렁였다(1→0.499, 2→0.401, 3→0.614, 5→0.776, 12→0.659). val의 anxious는 651장·29명뿐이라 표본이 작다. 5에폭이 뽑힌 건 실력이면서 동시에 운이기도 하고, **개선폭 +0.205 중 일부는 이 분산에 기인할 수 있다.** 계약(`best.pth`는 anxious recall 기준)대로 뽑았지만, 재현성이 걱정되면 시드를 바꿔 2~3회 더 돌려 분산을 재 보는 게 맞다.

**스펙 §1.4 fallback은 쓰지 않았고, 쓸 필요도 없었다.** anxious recall이 목표대로 올랐으므로 다수결 없음 샘플을 weight 0.5로 회수하는 레버는 아껴 둔다.

## 5. τ (백엔드 "other" 게이트)

**val에서 고르고 test에서 보고**했다. 선택 규칙은 top-1 확률이 정답/오답을 가장 잘 가르는 지점(Youden J 최대) — 파라미터가 없다.

**선택된 τ = 0.94** (val 커버리지 0.617 / 통과분 정확도 0.9589, test 커버리지 0.516 / 통과분 정확도 0.9466).

**이 값은 공격적이니 팀이 다시 볼 것.** Youden J는 0.85~0.99 구간이 거의 평평해서 사실상 가장 보수적인 끝을 고른다. τ=0.94면 test 프레임의 **절반이 "other"로 버려진다.** 3fps에서 5초 연속 판정을 해야 하는데 절반이 빠지면 알림이 늦거나 안 뜰 수 있다. 커버리지 기준으로 다시 고르는 편이 제품에 맞을 수 있다 (val 기준):

| τ | 커버리지 | 통과분 정확도 |
|---|---|---|
| 0.50 | 0.983 | 0.843 |
| 0.70 | 0.865 | 0.896 |
| 0.80 | 0.793 | 0.917 |
| 0.90 | 0.687 | 0.939 |
| **0.94** | **0.617** | **0.956** |

전체 곡선은 `artifacts/deliverable/history.json`의 `tau_curve`와 `artifacts/report/tau_curve.png`에 있다.
